## 1. 화면 구조
- 탭 3개: 외근 · 보고서 · 내 정보 (홈 탭 없앰, v102)
- 외근 탭은 상태에 따라 첫 화면이 바뀜
  - 외근 전: 1 지도 (지도 + 외근 내역 시트 + [▶ 외근 시작])
  - 외근 중: 7 외근 진행. 보고서·내 정보 탭에는 미니 바(7-4)
- 섹션과 번호
  - 외근 탭 · 외근 전: 1 지도, 2 외근 내역, 3 외근 상세
  - 현장 (외근 전·중 공통): 4 현장 검색, 5 현장 상세
  - 외근 탭 · 외근 중: 6 외근 준비, 7 외근 진행, 8 체크인 · 현장 기록
  - 9 보고서, 10 내 정보, 11 로그인·회원가입
- 전체 흐름은 Figma '0 화면 흐름' 보드 참고
- 위치 지도 화면(3-8, 3-9, 5-10, 8-9~8-12)은 캔버스·Figma에서 출발 화면 바로 아래 줄에 있음
- 지도 범위 (정적 지도안, v125): 아래 화면만 배경 지도 대신 정적 지도 카드. 그 밖의 화면은 기존대로 배경 지도
  - 외근 상세(3~3-6): 경로 카드, 누르면 3-8 경로 지도
  - 현장 상세(5~5-4): 이 현장 핀만 보이는 카드(350×132) + [크게 보기] → 5-10 위치 지도(주변 현장 핀 포함)
  - 체크인(8~8-5): 체크인 현장 핀 + 내 위치 카드(350×120) + [크게 보기] → 위치 지도(8-9~8-12, 주변 현장 핀 포함, 닫으면 출발 화면). 새 현장(8-3·8-5)은 위치 오차 원 포함
  - 위치 지도는 화면 하나로 만들고 닫기는 '뒤로'로 처리하면 됨. 프로토타입은 돌아갈 곳마다 화면을 따로 둔 것(추론)
  - 3-7 방문 기록 수정: 같은 카드(350×120) + [크게 보기] → 3-9 위치 지도(주변 현장 핀 포함, 닫으면 3-7)
  - 구현: 카카오맵 정적 지도 REST API 또는 상호작용 끈 지도 뷰(추론, 확인 필요)

- 보고서 상태: 작성 전 / 작성 중 / 작성 완료. 목록 배지는 '✓ 작성 완료' '✎ 작성 중', 작성 전은 [보고서 작성] 버튼. 외근 상세는 '보고서 작성 완료' 같이 '보고서'를 붙임
- 들르지 않은 목적지: '건너뜀' 하나만 씀. 행의 보조 줄은 '체크인 없음'
- 저장 버튼: 기본 '저장'. 맥락이 필요할 때만 덧붙임('저장하고 다음 현장으로', '새 현장으로 저장', '3곳 저장')
- 말투: '-해요'체. 부탁은 '-해 주세요'('-하세요' 쓰지 않음). 지도 설정의 '단계구분도'는 '구역별'(추론: 행정구역별 색칠)
- 약관 동의 칸은 처음에 모두 비어 있음(11-2)
- 4 현장 검색·4-1·4-2의 목적지 버튼은 5 현장 상세처럼 머리 오른쪽(목록 '+'를 가리지 않게)
- 예시 데이터 기준: 조치 상태·날짜는 외근 상세(3·3-2) 기록을 따름. 낙동대로 351은 10월 8일 조치 전, 하신중앙로 12는 10월 8일 조치 완료. 요일은 기존 예시 날짜(2025년 달력)에 맞춤

## 정책 결정 (2026-10-16, v133)
- 보고서 저장(9-2): 작성 전 현장이 남아 있으면 9-12 확인 창 '1곳이 아직 비어 있어요' [계속 작성][저장]. 저장하면 빈 현장은 빈 채로 보고서 완료
- 체크인 닫기(8 계열 공통): 8-13 확인 창 '체크인을 그만둘까요?' [계속 기록][그만두기]. 그만두면 이번 방문(체크인·사진·메모)을 버림
- 이 현장 건너뛰기: 방문하지 않은 것으로 처리. 방문 수에 넣지 않고 외근 상세에 '건너뜀'으로 표시, 다음 목적지로
- 저장 대기·실패가 남은 채 외근 종료: 확인 창 없음. 앱은 계속 다시 보내고 서버가 받아 처리
- 사진으로 여러 곳 등록(8-7): 등록한 현장마다 방문 1건으로 셈
- 보고서 삭제(9-3, 9 목록 '작성 중' 카드): 9-13 확인 창 '보고서를 삭제할까요?' '외근 기록은 그대로 남아요.' [취소][삭제]. 삭제 후 그 외근은 '보고서 작성 전'으로

비밀번호 찾기 제한값 (v113, B안)
- 이메일 6자리, 안전한 난수, 1회용
- 유효 5분, 다시 보내기 60초 뒤
- 한 번호로 5번 틀리면 그 번호만 무효, 계정 잠금 없음
- 발송 1시간 5통, 새 번호를 보내면 이전 번호 무효
- 가입 여부와 관계없이 같은 응답, 재설정 후 다른 기기 세션 무효화
