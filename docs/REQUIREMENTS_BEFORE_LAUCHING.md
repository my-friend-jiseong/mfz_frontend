# 일가요 서비스 추가 개발 권장 기능

현재 서비스 구현 상태를 기준으로 개인정보처리방침, 위치정보 이용약관 및 Google Play / Apple App Store 심사를 원활하게 통과하기 위해 추가를 권장하는 기능입니다.

---

# 🔴 필수 구현 권장 기능

## 1. 회원 탈퇴 기능

### 현재 상태

- 앱 내 회원 탈퇴 기능 없음
- 운영팀 이메일로 요청 후 수동 처리

### 문제점

- Apple App Store는 계정을 생성하는 앱의 경우 **앱 내부에서 계정을 삭제할 수 있는 기능**을 요구합니다.
- 현재 개인정보처리방침과 실제 서비스가 일치하지 않습니다.

### 권장 구현

프로필 화면에 아래 메뉴를 추가합니다.

```
프로필

내 정보 수정

비밀번호 변경

회원 탈퇴
```

회원 탈퇴 절차

```
회원 탈퇴

↓

삭제되는 정보 안내

↓

비밀번호 재입력

↓

최종 확인

↓

탈퇴 완료
```

### 삭제 대상

- 회원 기본정보
- 외근기록
- 방문기록
- 업무보고
- 사진
- 메모
- 로그인 세션 및 토큰

---

## 2. 회원 탈퇴 API

### 현재 상태

회원 삭제 API가 존재하지 않습니다.

### 권장 구현

```
DELETE /api/me
```

또는

```
DELETE /api/users/me
```

처리 과정

```
회원 탈퇴

↓

DELETE API 호출

↓

개인정보 삭제

↓

로그아웃

↓

탈퇴 완료
```

### 장점

- 운영팀 수동 삭제 불필요
- 개인정보처리방침과 일치
- 앱스토어 심사 대응 가능

---

# 🟡 구현 권장 기능

## 3. 개인정보 관련 메뉴 추가

설정 또는 프로필 화면에 다음 메뉴를 제공합니다.

```
설정

├ 이용약관
├ 개인정보처리방침
├ 위치정보 이용약관
├ 문의하기
└ 로그아웃
```

### 목적

- 언제든 약관 확인 가능
- 심사 시 접근성 향상

---

## 4. 문의하기 기능

현재는 이메일 주소만 존재합니다.

### 권장 구현

```
문의하기

↓

메일 앱 실행

↓

support@ilgayo.co.kr
```

### 문의 가능한 내용

- 개인정보 열람
- 개인정보 수정
- 개인정보 삭제
- 회원 탈퇴
- 서비스 문의

---

## 5. 위치 권한 안내 화면

현재는 위치 권한 요청만 수행됩니다.

### 권장 안내 문구

```
현재 위치는

• 지도 표시
• 현장 위치 입력
• 주변 현장 확인

기능에만 사용됩니다.

백그라운드 위치는 수집하지 않습니다.
```

### 목적

- 사용자 신뢰도 향상
- 개인정보처리방침과 일치

---

## 6. 개인정보 삭제 안내

회원 탈퇴 화면에 아래 내용을 표시합니다.

```
회원 탈퇴 시

• 개인정보가 삭제됩니다.
• 법령상 보관 대상 정보는 관련 법령에 따라 별도 보관될 수 있습니다.
```

※ 필수 기능은 아닙니다.

# 최종 권장 구현 목록
