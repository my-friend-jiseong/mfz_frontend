# 안드로이드 스토어 출시 준비도 — 차단 요소 정리

> **상태**: 검토 (2026-06-07 실측 감사 — MVP 동결 직후 기준)
> **결론**: **지금 바로는 출시 불가.** 코드·인프라는 출시급에 근접하나 차단 4건 + 절차 요인 존재. 차단이 모두 코드 대수술이 아니라 **자산·설정·문서 수준**이라 해소 비용은 낮은 편.

| 크래시 모니터링 | Sentry 연동. 프로드 번들 크래시 2건 수정 이력(2026-06-05) — 실기기 프로드 검증 존재 |
| 권한 선언 | 위치·카메라·사진 한국어 문구 정비 (단 ⛔-4 불일치 잔존) |
| 스토어 스크린샷 소스 | `docs/presentation/screenshots/` 24장 재활용 가능 |

## ⛔ 차단 — 출시 전 필수 (2026-06-07 실측 확인)

| # | 차단 요소 | 실측 근거 | 해소 방법 | 담당 |
|---|---|---|---|---|
| 1 | **앱 아이콘 플레이스홀더** | `assets/icon.png`·`adaptive-icon.png` 둘 다 파란 바탕 "M" (이미지 열어 확인) | 일가요 브랜드 아이콘 제작 (1024px + adaptive foreground), 스플래시도 함께 점검 | 디자인(사용자) |
| 2 | **개인정보 처리방침 URL 사망** | 앱 내 링크 `ilgayo.kr/terms`·`/privacy` → 도메인 미해석(000). `ilgayo.co.kr` 쪽도 404 | 정적 페이지 2장(처리방침·이용약관) 호스팅 — 백엔드 1시간 작업. 호스팅 후 `app/(tabs)/profile.tsx` 의 URL 상수 교체. **Play Console 은 살아있는 처리방침 URL 필수** (위치+사진 수집 앱이라 데이터 안전 양식과 교차 검증됨) | 백엔드 (착수 시 backlog 등재) |
| 3 | **production 빌드에 카카오 키 미주입** | `eas.json` 의 `EXPO_PUBLIC_KAKAO_JS_KEY` 가 preview 프로필에만 존재 → production aab 는 **지도가 placeholder 인 채로 빌드됨** | EAS Secrets 에 키 등록 후 production env 연결 (eas.json 하드코딩 금지 — 하단 보안 항목) | 프론트 |
| 4 | **폐기 기능 권한 잔재 + 문구 불일치** | 음성 메모는 ERD v2 폐기(`src/utils/media.ts` 주석)인데 `RECORD_AUDIO`·`MODIFY_AUDIO_SETTINGS`·`expo-av` 플러그인·마이크 문구 잔존. 위치 문구는 "도착 자동 감지"(제거된 기능) 기준 — 실제 용도는 현 위치 등록·빠른 촬영 매칭 | `app.json` 권한·플러그인·문구 정리 + `expo-av` 의존 제거. 데이터 안전 양식과 모순되면 심사 리젝 사유 | 프론트 |

## ⚠️ 절차·품질 — 차단은 아니나 일정 요인

| 항목 | 내용 |
|---|---|
| **비공개 테스트 요건** | Play **개인** 개발자 계정 신규는 테스터 12명 × 14일 비공개 테스트 후 프로덕션 가능 → 계정 유형 확인 필수, 개인이면 **최소 +2주** |
| 스토어 등록정보 | 앱 설명·피처 그래픽(1024×500)·데이터 안전 양식·콘텐츠 등급 설문 |
| **위치기반서비스(LBS) 신고** | 위치정보법상 위치기반서비스사업 신고 대상 여부 **확인 필요** (소규모 사업자 간이신고 제도 있음 — 법적 판단이므로 단정하지 않음) |
| destinations 클라이언트 저장 | backlog §11 — 기기 변경 시 외근 계획 유실. 스토어 리뷰에 맞을 품질 구멍 |
| 보안 정리 | `eas.json` 에 카카오 JS 키 커밋됨 (README 의 키 커밋 금지 규칙 위반). 도메인 제한 키라 치명도는 낮으나 EAS Secrets 이전 + 키 재발급 권장 |
| 백엔드 운영 내성 | 단일 서버 구성으로 추정 — 장애 시 앱 전면 불능. 출시 규모에선 허용 가능하나 인지 필요 |

## 권장 순서 (해소 시나리오)

1. ⛔-3·4 (프론트 설정 정리 — 반나절)
2. ⛔-2 (백엔드 정적 페이지 — backlog 등재 후 1일)
3. ⛔-1 (아이콘 — 디자인 소요에 따름)
4. production aab 빌드 → 실기기 설치 검증 (지도 키·권한 다이얼로그·딥링크)
5. Play Console: 계정 유형 확인 → 등록정보·데이터 안전 양식 → (개인 계정이면) 비공개 테스트 14일 → 프로덕션 심사

> 체감 일정: 조직 계정이면 **1주 내외**, 개인 계정이면 비공개 테스트 요건으로 **3주 내외**.
