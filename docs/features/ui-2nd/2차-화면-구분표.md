# 2차 개선본 화면 구분표 (Claude Code 구현용)

- 기준: Claude Design 캔버스 v139 = Figma 파일 `MlfpDS0wOeN90iNl5JCPWp` 페이지 `UI - 2차 개선본` (프레임 94장 + 화면 흐름 1장)
- 목적: Figma 프레임 하나가 곧 라우트 하나가 아님. 프레임마다 실제로 무엇을 만들지(화면, 상태, 시트, 메뉴, 확인 창) 정해 둔 표
- 종류별 개수: 화면 26, 상태 38, 시트 8, 메뉴 5, 확인 창 9, 전체 지도 7, 외부 1

## 종류 정의
| 종류 | 만들 것 |
|---|---|
| 화면 | 라우트(expo-router 파일) 하나. 같은 컴포넌트를 모드로 재사용하는 경우는 메모에 적음 |
| 상태 | 기준 화면의 상태 하나(데이터·오류·로딩 등). 라우트를 새로 만들지 않음 |
| 시트 | 기준 화면 위에 뜨는 바텀 시트(`@gorhom/bottom-sheet`). 프레임에 그려진 뒤 배경은 기준 화면 복사본 |
| 메뉴 | 기준 화면의 ⋯·+ 버튼에서 뜨는 팝오버 메뉴 |
| 확인 창 | 기준 화면 위 가운데 확인 대화상자(`ConfirmDialog` 계열) |
| 전체 지도 | 공통 전체 지도 화면 하나(모달 라우트). 프레임마다 핀·오차 원만 다름. 닫으면 연 화면으로 |
| 외부 | 직접 만들지 않음(SDK 화면) |

## 읽는 법
- `기준`은 그 상태·시트·메뉴가 속한 화면 번호
- `여는 곳·조건`은 Figma 프레임 위 캡션과 같음. 화면 이동은 이 칸과 인수인계 문서를 따름
- 프로토타입 연결은 대표 화면 하나로 이어 둔 곳이 있음(예: 7-8 [체크인] → 8 낙동대로 351). 연결이 가리키는 예시 데이터를 그대로 따르지 말 것
