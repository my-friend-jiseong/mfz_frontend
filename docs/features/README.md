# features — 앱을 바꾸는 일

> **규약**: 일 하나 = 폴더 하나. 주 문서는 각 폴더의 `README.md`, 머리에 상태·백로그 연결을 적는다.
> 구현이 끝나도 폴더는 옮기지 않고 상태만 닫는다. 규칙 전문은 [conventions/documentation.md](../conventions/documentation.md).

## 상태 표기
- `검토` — 방향만 잡힘, 명세 미완
- `확정` — 사용자/팀 결정 완료, 착수 대기
- `착수` — 개발 중
- `구현 완료` — 배포됨
