## 1. 공통

### 1.1 플랫폼 · UI

- 모바일 우선, 기준 폭 390px.
- DesignSystem 토큰(색, spacing, radius, typography, touch-target)을 코드 토큰과 대응시킨다.
- 인터랙티브 컨트롤 최소 터치 영역 **44×44pt**.
- 탭 루트(외근·현장·보고서·내 정보)에는 뒤로가기를 두지 않는다.
- 푸시 화면은 상단 헤더와 뒤로가기를 둔다. **[변경]** 회원가입도 헤더 뒤로가기로 로그인에 복귀한다.
- 모달형 화면(현장 수정, 계정 삭제)은 본문 `취소`로 닫는다.

### 1.2 조작 패턴

| 패턴 | 동작 |
|---|---|
| 주행동 | 화면 1차 영역에만 상시 노출 |
| 오버플로 `···` | 하단 액션 시트. 스크림 탭 시 닫기 |
| 카드/행 탭 | 상세 진입 또는 펼침 |
| **[신규]** 펼침 | 외근 정리의 방문 카드 탭 또는 `⌄` 탭 시 카드 아래에 요약 영역을 펼침. 다시 탭하면 접힘 |
| **[신규]** 스와이프 삭제 | 외근 정리의 방문 행을 왼쪽으로 밀면 빨간 `삭제` 노출. 탭 시 방문 삭제 |
| 카테고리 편집 | 행 탭 인라인 수정, `×` 삭제 |
| 하단 액션 바 | 화면의 주 버튼은 최하단 고정 바에 둔다. 흰 배경, 위쪽 1px 구분선, 좌우 16px. 버튼 높이 48~52px. 보조·삭제 버튼은 왼쪽(내용 너비), 주 버튼은 오른쪽(남은 너비). 적용: 체크인(`보고서 작성`·`체크인 완료`), 방문 수정(`방문 삭제`·`저장`), 현장 목록(`새 현장`·`촬영`), 외근 정리, 현장 선택, 진행 중 외근. 긴 입력 폼(현장 등록·수정, 회원가입, 계정 삭제, 보고서 수정)은 내용 끝에 둔다 |
| 헤더 | 모든 하위 화면은 `←`와 화면 제목을 가진다. 편집 화면에는 `···`를 두지 않는다 |
| 파괴적 삭제(현장, 보고서, 방문, 계정) | 확인 후 API 호출 |
| **[변경]** 조회 전용 | 현장 상세의 메모·사진, 방문 상세의 메모·사진은 편집 컨트롤을 두지 않는다 |

### 1.3 방문 데이터 쓰기 규칙 [신규]

| 화면 | 방문 결과 상태 | 사진 | 메모 |
|---|---|---|---|
| 체크인 | 쓰기 | 쓰기 | 쓰기 |
| 방문 수정 | 쓰기 | 쓰기 | 쓰기 |
| 방문 상세 | 읽기 | 읽기 | 읽기 |
| 외근 정리 (펼침) | 읽기 | 읽기 | 읽기 |
| 현장 상세 | 읽기 (방문 이력) | 읽기 | 읽기 |

- 체크인·방문 수정에서 저장한 값은 **같은 현장의 현장 상세에 즉시 반영**된다.
- 체크인의 모든 입력은 선택이다. 미입력 시 경고, 확인 팝업, 저장 차단을 하지 않는다.

### 1.4 방문 결과 상태 [변경]

| 코드 | 표시 | 설정 시점 |
|---|---|---|
| `UNDECIDED` | 미정 | 기본값. 미방문 또는 체크인 없이 건너뛴 경우 |
| `COMPLETED` | 완료 | 체크인 |
| `ABSENT` | 부재 | 체크인 |
| `REFUSED` | 수취거절 | 체크인 |
| `ADDRESS_UNKNOWN` | 주소불명 | 체크인 |
| `REVISIT` | 재방문필요 | 체크인 |
| `OTHER` | 기타 | 체크인 |

`예정` 표기는 사용하지 않는다. 진행 여부(예정·체크인·건너뜀)는 결과 상태와 별도로 표시한다.

## 2. 화면 플로우

### 2.1 탭 구조

```
하단 탭 (루트 화면에서만 노출)
├ 외근   → 외근 내역 (목록)
├ 현장   → 현장 (목록)
├ 보고서 → 보고서 (목록)
└ 내 정보 → 내 정보 · 홈
```

### 2.2 화면별 연결

`←`는 뒤로가기(직전 화면)다.

**인증**

| 출발 화면 | 조작 | 도착 |
|---|---|---|
| 로그인 | `로그인` | 외근 내역 (실패 시 로그인·오류) |
| 로그인 | `회원가입` | 회원가입 |
| 회원가입 | 헤더 `←` | 로그인 |
| 회원가입 | `가입하고 시작하기` | 외근 내역 (실패 시 회원가입·오류) |

**외근**

| 출발 화면 | 조작 | 도착 |
|---|---|---|
| 외근 내역 | 종료된 외근 카드 | 외근 정리 |
| 외근 내역 | 진행 중 외근 카드 | 진행 중 외근 |
| 외근 내역 | `외근 시작` | 현장 선택 |
| 현장 선택 | `다음 (N)` | 방문 순서 확인 |
| 방문 순서 확인 | `외근 시작 (N곳)` | 진행 중 외근 |
| 방문 순서 확인 | 현장 오른쪽 `▲` / `▼` | 같은 화면에서 앞·뒤 현장과 순서 교체 |
| 진행 중 외근 | `길찾기` | 인앱 길안내 |
| 진행 중 외근 | `체크인` | 체크인 |
| 진행 중 외근 | 목적지 행 | 방문 상세 |
| 진행 중 외근 | `···` | **팝업** 진행 중 외근 · 더보기 |
| 진행 중 외근 | `외근 종료` | 외근 정리 |
| 체크인 | `체크인 완료` | 진행 중 외근 (다음 목적지). 마지막 목적지면 전체 완료 상태 |
| 체크인 | **[신규]** `보고서 작성` | 외근의 보고서가 없으면 보고서 작성, 있으면 이 현장의 현장 보고 작성 |
| 체크인 | `←` | 진행 중 외근 (저장하지 않음) |
| 진행 중 외근 · 전체 완료 | `외근 종료` | 외근 정리 |
| 외근 정리 | 헤더 제목 | 외근 정리 · 제목 수정 (같은 화면에서 인라인 수정, `완료` 시 복귀) |
| 외근 정리 | 방문 카드 / `⌄` | 같은 화면에서 펼침 (방문 수정·위치·사진·메모) |
| 외근 정리 (펼침) | `방문 수정` | 방문 수정 |
| 외근 정리 | 방문 행 스와이프 → `삭제` | 확인 후 방문 삭제, 목록 갱신. 보고서에 반영된 방문이면 차단 안내 |
| 외근 정리 | `보고서 작성` | 보고서 작성 |
| 방문 수정 | `저장` | ← 외근 정리 |
| 방문 수정 | `방문 삭제` | 확인 후 외근 정리 |

**현장**

| 출발 화면 | 조작 | 도착 |
|---|---|---|
| 현장 목록 | 현장 카드 | 현장 상세 |
| 현장 목록 | `새 현장` | 현장 등록 |
| 현장 등록 | `현장 등록` | **[변경]** 저장 후 현장 목록 + 토스트 "현장이 등록되었습니다" (2초 후 사라짐) |
| 현장 상세 | `···` | **팝업** 현장 상세 · 더보기 |
| 현장 상세 | `길찾기` | 외부 지도 앱 또는 인앱 길안내 |
| 현장 수정 | `저장` / `취소` | ← 현장 상세 |

**보고서**

| 출발 화면 | 조작 | 도착 |
|---|---|---|
| 보고서 목록 | 보고서 카드 | 보고서 상세 |
| 보고서 작성 | `보고서 만들기` | 현장 보고 작성 (1/N) |
| 보고서 작성 | 현장 오른쪽 `▲` / `▼` | 같은 화면에서 앞·뒤 현장과 보고 순서 교체 |
| 현장 보고 작성 | **[신규]** `나중에 다시 작성` | 입력분 저장 후 진행 중 외근 + 토스트 "작성 중인 내용을 저장했어요" (2초 후 사라짐) |
| 현장 보고 작성 | `저장 후 다음 현장` | 현장 보고 작성 (다음 단계) |
| 현장 보고 작성 (마지막) | `저장 후 완료` | 보고서 상세 |
| 현장 보고 작성 | `사진 변경` / 사진 영역 | **팝업** 사진 |
| 현장 보고 작성 | `···` | **팝업** 현장 보고 작성 · 더보기 |
| 보고서 상세 | 상단 보고서 제목 | 보고서 상세 · 제목 수정 (인라인, `완료` 시 복귀) |
| 보고서 상세 | `내보내기` (미작성 현장 없음) | **팝업** 내보내기 |
| 보고서 상세 | `내보내기` (미작성 현장 있음) | **팝업** 미작성 경고 → `내보내기` 시 **팝업** 내보내기 |
| 보고서 상세 | `현장 보고 추가` | **[변경]** 현장 보고 추가 (빈 양식). 현장을 고른 뒤 `추가하고 돌아가기` → 보고서 상세 |
| 보고서 상세 | 현장 카드 `›` | 그 현장의 보고서 수정 |
| 보고서 수정 | `저장` | 보고서 상세 |
| 보고서 수정 | `취소` / `←` | ← 보고서 상세 |
| 보고서 수정 | `사진 변경` | **팝업** 사진 |
| 보고서 수정 | 현장 칸 (탭하여 변경) | **팝업** 현장 선택 (보고서의 현장 목록, 선택 시 해당 현장으로 전환) |
| 보고서 목록 | 보고서 카드 / 외근 줄 `›` | 보고서 상세 |

**내 정보**

| 출발 화면 | 조작 | 도착 |
|---|---|---|
| 내 정보 · 홈 | `내 정보 수정` | 내 정보 수정 |
| 내 정보 · 홈 | `카테고리 관리` | 카테고리 관리 |
| 내 정보 · 홈 | `로그아웃` | 로그인 |
| 내 정보 · 홈 | `회원 탈퇴` | 계정 삭제 |
| 계정 삭제 | `회원 탈퇴` | 로그인 |
| 계정 삭제 | `취소` | 내 정보 · 홈 |

### 2.3 팝업(액션 시트)과 이동

모든 시트는 스크림 탭으로 닫힌다.

| 팝업 | 여는 곳 | 항목 | 결과 |
|---|---|---|---|
| 진행 중 외근 · 더보기 | 진행 중 외근 `···` | 촬영 | OS 카메라 → 현재 방문 사진에 추가 |
| | | 이 방문 건너뛰기 | 현재 목적지 건너뜀, 결과 `미정` 유지, 다음 목적지로 |
| | | 현장 추가 | 현장 선택 → 외근에 추가 |
| 현장 상세 · 더보기 | 현장 상세 `···` | 현장 정보 수정 | 현장 수정 |
| | | 현장 삭제 | 확인 후 현장 목록 |
| 보고서 상세 · 더보기 | 보고서 상세 `···` | **[신규]** 보고서 수정 | 보고서 수정 |
| | | Word 다시 생성 | 시트 닫고 생성 진행 토스트 |
| | | 보고서 삭제 | 확인 후 보고서 목록 |
| 내보내기 | 보고서 상세 `내보내기` | Word 파일 (.docx) / PDF 파일 (.pdf) | 파일 생성 후 OS 공유·저장 |
| 미작성 경고 (대화상자) | 보고서 상세 `내보내기` | 취소 / 내보내기 | 취소: 닫기. 내보내기: 내보내기 시트 |
| 현장 보고 작성 · 더보기 | 현장 보고 작성 `···` | **[변경]** 이 현장은 나중에 채우기 | 현재 현장을 미작성으로 두고 다음 단계 |
| | | 이 현장 보고 삭제 | 확인 후 보고서 상세 |
| 사진 | 현장 보고 작성·보고서 수정 `사진 변경` | 촬영 / 앨범에서 선택 / 현장 사진에서 불러오기 / 사진 제거 | OS 선택기 또는 현장 사진 목록, 완료 후 시트 닫힘 |

### 2.4 주요 경로

```
[외근 수행]
외근 내역 → 현장 선택 → 방문 순서 확인 → 진행 중 외근
  → (길찾기) → 체크인(상태·사진·메모) → 진행 중 외근 → … 반복
  → 외근 종료 → 외근 정리

[방문 기록 수정]
외근 정리 → 방문 카드 펼침 → 방문 수정 → 저장 → 외근 정리
  (현장 상세의 메모·사진에 반영)

[보고서]
외근 정리 → 보고서 작성 → 현장 보고 (1/N … N/N) → 보고서 상세
체크인 → 보고서 작성 (보고서 없음) 또는 해당 현장 보고 (보고서 있음)
현장 보고 → 나중에 다시 작성 → 진행 중 외근
보고서 상세 → ··· → 보고서 수정 → 저장 → 보고서 상세
```

### 2.5 프로토타입과 실제 동작의 차이

| 항목 | 프로토타입 | 실제 앱 |
|---|---|---|
| 체크인 완료 | 시연용으로 `전체 완료`로 이동 | 다음 목적지가 있으면 진행 중 외근으로 복귀 |
| 삭제·저장·생성 | 화면 이동만 | API 호출과 결과 반영 |

## 10. 수락 기준

1. 진행 중 외근 첫 화면에 길찾기·체크인 외 예외 액션이 상시 노출되지 않는다.
2. 보고서 상세 현장 카드에 카드별 수정·삭제 버튼이 없고, 하단 `수정` 버튼도 없다.
3. 체크인·카테고리 관리·현장 등록·내 정보 수정·회원가입에서 뒤로가기로 나갈 수 있다.
4. 탭 루트 화면에 뒤로가기가 없다.
5. 현장 상세와 방문 상세에 메모·사진 편집 컨트롤이 없다.
6. 체크인에서 쓴 메모가 같은 현장의 현장 상세에 표시된다.
7. 체크인 없이 건너뛴 방문의 결과가 `미정`으로 표시된다.
8. 체크인은 아무 값도 입력하지 않아도 경고 없이 완료된다.
9. 방문 삭제 후 현장 목록에서 해당 현장이 사라지지 않고, 그 방문의 메모·사진만 현장 상세에서 사라진다.
10. 보고서 수정에서 사진과 설명까지 바꿀 수 있다.
11. 외근 내역에 주간 통계가 없다.
12. 외근 정리 헤더 제목을 탭해 외근 제목을 바꿀 수 있고, 방문 수정은 펼친 방문 카드에서 들어간다.
13. 보고서에 반영된 방문, 진행 중 외근에 포함된 현장은 삭제가 차단되고 안내가 뜬다.
14. 보고서에 건너뛴 방문이 나오지 않는다.
15. 보고서 작성 중 `이 현장은 나중에 채우기`로 넘긴 현장은 보고서 상세에 `미작성`으로 남는다.
16. 미작성 현장이 있는 보고서를 내보내면 확인 대화상자가 뜨고, 동의하면 빈칸으로 내보내진다.
17. 방문 순서 확인과 보고서 작성의 모든 항목에서 `▲`·`▼`로 현장 순서를 바꿀 수 있고, 바뀐 순서가 외근·현장 보고에 반영된다.
18. 체크인의 `보고서 작성`은 보고서가 없으면 보고서 작성, 있으면 해당 현장의 현장 보고로 이동한다.
19. 보고서 목록에 `보고서 작성` 버튼이 없다.
