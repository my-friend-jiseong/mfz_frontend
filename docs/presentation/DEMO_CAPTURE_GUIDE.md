# 데모 녹화 · 스크린샷 추출 가이드 (기기 캡처)

> 목적: **기기에서 데모 동선을 한 번 제대로** 진행하면서 → ① 슬라이드용 정지 스크린샷(S5~S8) ② S16 데모 영상 을 동시에 확보한다.
> 왜 기기인가: 웹/헤드리스 캡처는 테스트 데이터(글자깨짐·방문 0건·사진 없음)라 hero 컷이 안 나온다. 실데이터·실사진·실GPS는 기기에서만.
> 산출물 저장 위치: 찍은 PNG/영상을 `docs/presentation/screenshots/` 에 슬라이드 번호로 넣으면 됨 (예: `S5_field_new.png`). 그러면 발표 덱에 그대로 투입.

---

## 0. 사전 준비 — "깔끔한 데이터" 1세트 (★ 가장 중요)

지금 계정 데이터가 지저분(`체크인 테스트용 외근`, `해으으응`, `����2`, 방문 0건)하므로, **발표 전용으로 깔끔한 1세트**를 새로 만든다.

- **현장 2~3곳**: 실제 주소로 카카오 검색해 등록 — **데모 데이터 지역은 부산 실주소 기준**. **분류·상세주소에 이모지/특수문자 금지**(글자깨짐 원인). 예) "부산 연제구 중앙대로 1001", 분류 `정기점검`.
- **현장 이름·보고서·외근 제목 현실적으로**: `테스트`/`ㅁㄴㅇㄹ` 금지. 예) 외근 "연제구 정기점검 1차", 보고서 "연제구 정기점검 1차 결과".
- **완결된 외근 1건**: 현장 2곳을 실제로 체크인하고 **전·중·후 사진을 실제로 촬영/첨부**, 방문결과 상태 선택까지. → 이게 있어야 S6·S7가 채워진다.
- **사진**: 보기 좋은 현장 느낌의 사진 2~3장(전/중/후). 인물·민감정보 없게.

## 1. 녹화·캡처 방법 (한 번에 둘 다)

- 기기 **화면 기록**(iOS 제어센터 / Android 화면 녹화) **켜고 전체 동선 1회** 진행 → **S16 데모 영상**.
- 동시에, 아래 ★ 표시 화면에서 **잠깐 멈추고 기기 스크린샷**(전원+볼륨) → **슬라이드용 정지컷**.
  - 정지컷은 영상 프레임 추출보다 **기기 스크린샷이 더 선명**하다. 영상에서 뽑아야 하면 `ffmpeg -ss <시각> -i demo.mp4 -frames:v 1 out.png`.
- **품질 체크**: 세로 모드 · 라이트 모드 · 상단 상태바 깨끗하게(알림/배터리 경고 제거) · 각 ★ 화면 2~3초 정지.

## 2. 동선 + 슬라이드 매핑 (★ = 스크린샷 지점)

| 순서 | 동작 | 스크린샷 | 슬라이드 |
|---|---|---|---|
| 1 | 로그인 → 외근 탭 | | (영상 시작) |
| 2 | 현장 추가 → 주소검색 → 결과 선택 | ★ **좌표 채워진 상태** | **S5** `S5_field_new` |
| 3 | 외근 시작 → 현장 2곳 선택 → 순서 자동정렬 | ★ **정렬된 목록(거리·ETA)** | **S5** `S5_trip_order` |
| 4 | 외근 진행(active) 지도 | ★ **마커+경로 지도** | **S6** `S6_trip_active` |
| 5 | 체크인 → 전·중·후 사진 + 방문결과 상태 | ★ **사진 3장+상태칩** | **S6** `S6_checkin` |
| 6 | 외근 종료 → 보고서 작성 | ★ **현장별 전·중·후 카드** | **S7** `S7_report` |
| 7 | 현장/외근 탭의 지도 대시보드 → 필터 토글 | ★ **필터 적용 전·후 2장** | **S8** `S8_dashboard_1/2` |

> S5~S8은 위 7컷으로 전부 커버된다. S1·S14는 BASE 보존, 나머지(S2·S4·S9·S13 도식)는 스크린샷이 아니라 **도식**이라 별도.

## 3. 도식(스크린샷 아님)은 Desktop이 제작

S2(3단절→통합), S4(라이프사이클 플로우), S9(아키텍처), S13(거점→점 재정의)은 그림이다. 브리프 §10에 표시돼 있고, Claude Desktop이 만들거나 직접 그린다.

## 4. 참고 — 기존 웹 캡처

`screenshots/` 폴더의 `00_login`~`08_trip_active`(8장)는 **테스트 데이터 기준 참고용**이다(글자깨짐·방문0건). 단, `01_trips_list`·`04_reports_list`의 **지도+필터 뷰**는 데이터와 무관하게 S8 보조로 쓸 만하다. 나머지는 위 기기 캡처로 대체.
