# 결과보고서 「테스트 및 검증」 — 피드백 및 수정사항 (작성자 제공용)

> 사하구 현장 점검 업무 담당자 미팅 피드백을 기준으로 기능을 맞춰 검증한 내용 요약(약 400자). 결과보고서 2-(3) 테스트 및 검증 칸에 그대로 또는 다듬어 사용.

---

실증 단계에서 사하구 공공시설물 현장 점검 업무 담당자와의 미팅으로 실제 현장 요구를 수집하고, 이를 기준으로 기능을 맞춰 검증했다.

반영·확인된 사항은 다음과 같다. **①** '사무실 복귀 후 웹에서 별도 작성' 흐름 제거 요구 → 외근 동선에서 바로 작성되는 단일 화면 등록·보고서 작성 마법사로 검증. **②** 촬영 시 최근접 등록 장소 자동 매핑·현 위치 핀 자동 세팅 요구 → 빠른 촬영의 최근접 현장 자동 매칭으로 구현하고 매칭 로직 단위 테스트로 확인. **③** 엑셀 목록에 없는 신규 시설물 등록 흐름 → 매칭 실패 시 좌표·사진을 들고 새 현장 등록으로 폴백해 해소. **④** 사진 전·중·후 구조 요구 → 체크인·보고서에 그대로 반영. **⑤** 출장=프로젝트 단위로 점검 지점 N개를 묶고 진행도를 확인하는 요구 → 외근 구성·진행률 UI로 검증.

한편 hwpx 보고서 출력과 시설물 엑셀 일괄 입력은 실수요로 확인해 2학기 과제로 이관했다.
