이번주 진행사항

1. 개발내용

⚫ 지도 히트맵 전면 개편
  ◼ 웹·앱 히트맵을 밀도 추정(KDE) 방식 캔버스로 교체, 단계구분도 채색을 절대 건수 구간으로 변경
  ◼ 실제 색 척도와 일치하는 범례 추가, 줌 수준에 따라 표시 반경 연동
  ◼ 줌 중 다시 그리기 생략·화면 밖 데이터 제외로 줌아웃 시 끊김 해소, 행정구역 경계 데이터를 앱에 내장해 오프라인에서도 동작
⚫ 현장 등록·수정 단일 화면 통합
  ◼ 단계로 나뉘어 있던 등록 절차를 주소 검색·현 위치·핀 지도가 실시간 연동되는 한 화면으로 통합
  ◼ 장소명(POI) 검색 추가, 핀 이동 시 주소 자동 갱신, 진입 시 현 위치 자동 측위
  ◼ 현장 수정 화면도 동일 구조로 통일
⚫ 빠른 촬영(사진 자동 현장 매칭) 신설
  ◼ 촬영 좌표로 최근접 현장을 자동 매칭해 사진을 바로 첨부, 매칭 실패 시 현장 선택·새 현장 등록 경로 제공
  ◼ 현장 목록과 진행 중 외근 화면에 진입점 추가, 매칭 로직 단위 테스트 작성
⚫ 보고서 작성 마법사·위치도 추가
  ◼ 보고서 생성 직후 현장 보고를 단계별로 작성하는 마법사 도입
  ◼ 작성·상세 화면에 연결 외근의 현장 전체를 담는 인라인 위치도 추가
  ◼ 작성 화면이 외근 정보를 반복 요청해 버튼이 비활성화되던 문제 수정
⚫ 기기 검증 버그 수정
  ◼ 로그인 직후 앱이 종료되던 크래시 — 화면 전환 이중 처리 제거로 수정
  ◼ 목록이 끝까지 스크롤되지 않던 문제 — 시트 높이 미적용과 목록 1페이지 절단 두 원인 모두 수정
  ◼ 앱에서 지도가 백지로 뜨던 문제(지도 등록 도메인 지정), 사진 빈 칸 표시, 방문 수 0건 표시, 외근 중 지도가 목적지로 끌려가던 문제 수정
⚫ 스토어 출시 및 기말 발표 준비
  ◼ 안드로이드 설치 파일(APK) 자동 빌드 구축 — release 반영 시 자동 빌드 후 GitHub Release 첨부
  ◼ 출시 준비도 점검으로 차단 요인 4건 식별, 이 중 2건(운영 지도 키 주입, 불필요 권한 제거) 해소
  ◼ 발표용 화면 캡처 24장·시연 영상(약 2분) 자동 촬영 스크립트 작성, ERD·화면 구조도 최신화
  ◼ 2학기 로드맵 문서화 — 출시 준비→인앱 경로→보고서 포맷→현장 재정의→엑셀 입출력 순서 확정
