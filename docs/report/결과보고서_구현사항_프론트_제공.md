# 결과보고서 「구현 내용」 — 프론트엔드 개발 현황 (작성자 제공용)

> 프론트엔드 담당이 보고서 작성자에게 전달하는 구현 현황 요약(약 800자). 결과보고서 2-(2) 구현 내용 칸에 그대로 또는 다듬어 사용.

---

일가요 프론트엔드는 React Native + Expo 단일 코드베이스로 iOS·Android·Web을 동시 지원하도록 구현했다. 외근 풀 라이프사이클(현장 등록 → 외근 구성 → 진행 → 체크인 → 종료 → 보고)을 끊김 없는 한 동선으로 완성했다.

핵심 화면은 다음과 같다. **① 현장 등록** — 주소 검색(도로명·지번·장소명 POI)·현 위치 GPS·핀 지도 드래그가 한 화면에서 실시간 연동되며, 중복 주소 확인과 한국 영역 가드를 포함한다. **② 빠른 촬영** — 버튼 한 번으로 GPS 측위 후 최근접 현장을 자동 매칭해 사진을 즉시 등록하고, 근처에 현장이 없으면 좌표·사진을 들고 새 현장 등록으로 폴백한다. **③ 진행 중 외근** — 해당 외근만 스코프된 지도에서 목적지 관리·진행률·길찾기를 제공하고, 시작 전 최근접 이웃 휴리스틱으로 방문 순서를 자동 정렬한다. **④ 체크인** — 방문결과 6종과 전·중·후 사진을 기록한다. **⑤ 구조화 보고서** — 작성 마법사가 현장별 전·중·후 사진과 캡션을 묶어 Word 문서로 다운로드한다. **⑥ 지도 대시보드** — 마커·KDE 히트맵·단계구분도 3종 표시와 행정구역 경계 오프라인 렌더, 기간 필터를 지원한다.

인증은 JWT + refresh 토큰 회전과 멀티탭 레이스 복구를 구현했고, 디자인 시스템은 색 + 형상 + 라벨 3중 인코딩으로 접근성을 확보했다. 일부 항목은 프론트 UI·로직을 완성하고 백엔드 영속화만 대기 중이다.
