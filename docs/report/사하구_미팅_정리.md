# 사하구 현장 점검 모바일 앱 기획 - 미팅 정리

## 1. 프로젝트 개요

- **대상 업무**: 사하구 공공시설물 현장 점검·보수 (가로등, 하수도, 버스정류장, 경로당 등)
- **목표**: 사진 촬영 → 보고서 작성 → 이메일 송부까지 모바일에서 완결
- **최종 유통**: 온나라지식 업로드

## 2. 핵심 방향성

- **현장 완결성**: 사무실 복귀 후 웹에서 따로 작성하는 흐름 제거. 외근 동선에 따라 자연스럽게 작성되게.
- **조작 직관성**: 한 손 조작 가능. 카카오택시 수준의 단순함이 레퍼런스.
- **MVP 가볍게**: 핵심 기능 차별화에 집중하고, 확장은 실사용 피드백 기반으로.

## 3. 주요 기능

### 3-1. 위치·매핑

- 촬영 시 가장 가까운 등록 외근장소에 **자동 매핑**
- 기본 위치: 현재 위치를 핀으로 자동 세팅
- 촬영 후 **자동 줌인**으로 핀 이동을 쉽게 (한 손 조작)
- **오프셋 처리**: 멀리서 찍는 케이스 (예: 하수도 뚜껑 민원)
- 알려진 이슈: 사진 EXIF GPS와 휴대폰 현재 위치 불일치

### 3-2. 사진 관리

- 상태별 구조: **전·중·후**
- 각 상태에 다수 사진 가능, 상태값별 사진 개수 룰 차등 (구체안 미정)
- **대표 사진 선택 UX** 필요
- 파일 다운사이징 필수 — **최대 20MB**

### 3-3. 출장 관리 (프로젝트화)

- 출장 = 프로젝트 단위, 안에 점검 지점 N개를 묶음
- 예: "버스 승강장 점검" → 정류장 1·2·3
- 지점들을 지도에 표시하고 다니면서 상태 업데이트
- **진행도 UI**로 본인 작업 현황 확인

### 3-4. 보고서 생성·송부

- 폼 헤더값 읽어 **필수값 자동 채움**
- 출력 형식: **hwpx 우선, PDF 차선**
- 송부 경로: **무조건 이메일** (드라이브 차단)
- 앱에서 바로 이메일 발송 가능 여부 확인 필요

## 4. 데이터

- **제공받음**: 시설물 위경도 엑셀
- **사무실용 시각화 트랙(별도)**: 버스정류장·경로당 밀집도 등
- 분류 축: 행정구역·연도·금액별

## 5. 참고 사례

- **카카오택시**: 조작 직관성
- **모두의 출장**: 사진 이동 편의성

## 6. 미결정 / 추가 결정 필요

- "딕셔너리 구조 / 큰 지도 / 상세 지도 / 전·중·후" 구조 구체화
- 상태값 종류와 상태별 사진 개수 규칙
- 대표 사진 선택 방식 (자동 vs 수동)
- 보고서 템플릿의 정확한 필수 헤더 항목
- 행정구역·연도·금액별 뷰의 활용 시나리오
- 내부망 반입 제약 범위

## 7. 추가 점검 포인트 (제안)

- 오프라인 모드 (통신 음영 지역)
- 텍스트 메모·음성 입력 병행
- 결재선·검토자 단계 유무
- 사진 속 개인정보(얼굴·차량번호) 처리
- 엑셀 목록에 없는 신규 시설물 등록 흐름
- 사진 GPS 메타데이터 보존/삭제 정책
- 동일 시설물 재방문 이력 관리
