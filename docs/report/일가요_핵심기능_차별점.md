# 일가요 — 핵심 기능 / 차별점

> **한 줄 요약:** 현장 등록부터 Word 보고서 제출까지, 흩어진 외근 업무를 한 앱에서 완결한다.

**일가요**는 사하구 공공시설물 현장 점검·보수 업무자를 위한 모바일(React Native + Expo)·웹 통합 앱이다.
현장 점검 시작부터 보고서 생성까지 한 앱에서 끝내는 **외근 통합 플랫폼**을 지향한다.

---

## 1. 현장 등록 — 주소·지도·GPS 실시간 일체형
주소검색 / 현 위치 GPS / 핀 드래그를 **한 화면에서 실시간 연동**. 입력하면 핀이 움직이고, 핀을 끌면 주소가 역지오코딩으로 따라온다.
- **차별점:** 사무실 웹 폼이 아니라 **현장에서 즉석 등록**.
- **근거:** `app/(tabs)/fields/new.tsx`, `app/(tabs)/fields/[id]/edit.tsx`

## 2. 빠른 촬영(Quick Photo) — 촬영 위치 자동 현장 매칭
버튼 1회 → 직촬영 → GPS 측위 → **100m 반경 내 가장 가까운 현장 자동 추천** → 1탭 등록. 근처 현장이 없으면 수동 선택 또는 새 현장 등록으로 폴백.
- **차별점:** 외근 중 기록 마찰 최소화. **2학기 점(point) 자산 모델의 예고편**.
- **근거:** `src/components/fields/useQuickPhoto.ts`, `docs/reference/AUTO_PICTURE_REGISTRATION_PLAN.md`

## 3. 외근 풀 라이프사이클 — 시작·이동·기록·종료 단일 동선
현장 다중선택 → 외근 시작 → 길찾기(카카오 딥링크) → 체크인 → 사진·메모 기록 → 종료 → 보고서.
- **차별점:** 보고 시스템·길찾기 앱·촬영 앱을 **따로 쓰던 것을 하나로**.
- **근거:** `app/(tabs)/trips/active.tsx`, `app/(tabs)/trips/`

## 4. 방문 결과 6종 상태 — "갔는데 뭘 했는가"를 구조화
체크인 후 **완료·부재·거부·주소불명·재방문필요·기타** 중 택일(기타는 사유 10자 이상 필수). 상태별 색·형상·라벨 3중 인코딩.
- **차별점:** 사진만 모으는 게 아니라 **방문 실적을 정량화** → 추후 분석 가능.
- **근거:** `app/(tabs)/fields/[id]/checkin.tsx`, `src/types/entities.ts`

## 5. 작업 전·중·후 사진 슬롯
사진을 조치 전(before) / 중(pending) / 후(after) 3단계로 분류 저장 → 보고서에 현장별로 연순 정렬.
- **차별점:** 사하구 보고서 양식(전중후)과 **정확히 매칭**.
- **근거:** `app/(tabs)/reports/[id]/field-report.tsx`, `app/(tabs)/fields/[id]/checkin.tsx`

## 6. 보고서 작성 마법사 + Word 자동 생성
외근 선택 → 방문 현장별 빈 보고서 **자동 스캐폴드** → 차례로 채움 → **.docx 자동 변환·다운로드**.
- **차별점:** "사진 찍으면 보고서가 절반" — **사무실 HWP 편집 제거**.
- **근거:** `app/(tabs)/reports/new.tsx`, `src/stores/reportStore.ts`

## 7. 위치도(개요 지도) Word 최상단 자동 임베드
보고서 상세의 카카오맵 위치도를 네이티브 캡처 → 업로드 → Word 최상단 figure로 자동 삽입.
- **차별점:** 보고서 수신자가 **업무 구역을 한눈에 파악**.
- **근거:** `app/(tabs)/reports/[id]/index.tsx`, `docs/backend/release-2026-06-19-destinations-overview.md`

## 8. 지도 대시보드 3중 표시 + 행정경계
모든 현장을 지도에 축적. **마커(상태 색·형상) / 히트맵(KDE 밀도) / 단계구분도(시군구 경계 채색)** 전환 + 메모·사진 핀 토글 + 기간 필터(전체·1·7·30일).
- **차별점:** 외근 데이터가 **지도 위에 쌓이는** 시각화. 행정경계 GeoJSON 번들 내장.
- **근거:** `src/components/MapDashboard.tsx`, `src/components/KakaoMapWebView.tsx`

## 9. 방문 순서 자동 최적화
출발지 기준 **최근접 이웃(nearest-neighbor)** 휴리스틱 자동 정렬 + 거리·ETA 표시 + 진행 중 재정렬.
- **차별점:** 순방문 경로를 지도 위에서 먼저 제안.
- **근거:** `src/utils/routeOptimize.ts`, `app/(tabs)/trips/active.tsx`

## 10. 진행 중 외근 동적 관리
외근 진행 중 도착 표시·건너뛰기·**목적지 추가**·재정렬을 실시간 반영, 서버 영속화로 다른 기기/세션 동기화.
- **차별점:** 계획대로만 가는 게 아니라 **현장 상황에 실시간 대응**.
- **근거:** `src/stores/destinationStore.ts`, `app/(tabs)/trips/active.tsx`

## 핵심 어필 메시지

가장 강한 3개를 묶으면:

1. **외근 통합 라이프사이클** — 등록 → 이동 → 기록 → 보고를 한 앱에서
2. **구조화된 기록의 자산화** — 전·중·후 사진 + 방문 6종 상태 + Word 자동 생성
3. **지도 시각화** — 마커·히트맵·단계구분도로 업무 분포를 한눈에

> 1학기에 "거점 모델"에서 시작했으나, 빠른 촬영·자동 매칭 기능을 통해
> **2학기 "점 자산 모델"(정밀 좌표 기반 현장 생성)의 초석**을 마련했다.
